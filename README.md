# OneXray Enhanced Routing Samples

[简体中文](./readme/README.zh_CN.md)


Note:
1. All enhanced routes are not suitable for importing into iOS.
2. When importing, you need to download the rule data from github. Please make sure you can access [https://raw.githubusercontent.com/](https://raw.githubusercontent.com/), otherwise the import will fail.

## How to use

### One-click import

[One-click import](https://onexray.com/docs/routing/)

### Import via Clipboard

Depending on your location, copy the link below, then open the homepage of the App, click the "+" button in the upper right corner, and select "Read Clipboard".

Mainland China
```
https://github.com/OneXray/Routing/raw/refs/heads/main/cn.txt#CNRouting
```

Iran
```
https://github.com/OneXray/Routing/raw/refs/heads/main/ir.txt#IRRouting
```

Russia
```
https://github.com/OneXray/Routing/raw/refs/heads/main/ru.txt#RURouting
```

### Manual Input

Depending on your location, copy the link below, then open the homepage of the App, click the "+" button in the upper right corner, select "Subscribe Link", and paste the link into the input box.

Mainland China
```
https://github.com/OneXray/Routing/raw/refs/heads/main/cn.txt
```

```
https://github.com/OneXray/Routing/raw/refs/heads/main/ir.txt
```
